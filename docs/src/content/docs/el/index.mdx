Το αποθετήριο είναι το `ddd-cqrs`· τα πακέτα εγκαθίστανται από το npm scope `@cqrs-ddd/*`. Χρειάζονται Node.js 22.12 ή νεότερο και κανένα framework ή dependency-injection container, και διατίθενται με διπλή άδεια, AGPLv3 ή εμπορική: δείτε την [άδεια](https://github.com/aristoteliss/ddd-cqrs#license-and-commercial-use).
