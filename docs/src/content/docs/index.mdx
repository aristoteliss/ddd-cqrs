The repository is `ddd-cqrs`; the packages install from the npm scope `@cqrs-ddd/*`. They need Node.js 22.12 or later and no framework or dependency-injection container, and they are dual-licensed, AGPLv3 or commercial: see the [license](https://github.com/aristoteliss/ddd-cqrs#license-and-commercial-use).
