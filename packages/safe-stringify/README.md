# @cqrs-ddd/safe-stringify

Two JSON serializers with opposite goals, and the key-segment helpers that build
identity keys. No runtime dependencies and no framework.

**Documentation:** [guide](https://aristoteliss.github.io/ddd-cqrs/packages/safe-stringify/) · [API reference](https://aristoteliss.github.io/ddd-cqrs/api/cqrs-ddd/safe-stringify/) · [all packages](https://aristoteliss.github.io/ddd-cqrs/)

## Installation

```bash
npm install @cqrs-ddd/safe-stringify
# or
pnpm add @cqrs-ddd/safe-stringify
```

Requires Node.js 22.12 or later.

Published as an ES module; a CommonJS application loads it with `require()`.
